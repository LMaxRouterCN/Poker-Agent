# Poker Agent
>*Fake Agent*

这是一个利用现在LLM网页端免费额度实现的完全免费的低配版Agent

>叠甲:
>这是厚颜无耻的薅羊毛吗?
>\不是,因为它只是把你手动的操作自动化了,手动的缺点它一样有,而且它需要复用你的浏览器登录态,绕不过任何安全措施

## 引

llm输出消息 > 油猴脚本抓取消息中的指令 > 发送给本地服务 > 本地服务执行 > 本地服务发送回执给油猴脚本 > 油猴脚本将回执输入进输入框并发送 > llm收到回执并开始下一步工作

通过自定义几种标识符规定指令格式来识别指令,然后给llm看一下基础的使用须知让他按照规定的格式来输出文本,然后用 浏览器端的油猴脚本-本地服务-代码编译器扩展(可选,用于获取一些额外信息) 组成执行流程,

---

并且因为llm输出指令后本地服务会返回一段回执,这段回执正好可以用于开启下一次对话,而且这和单次对话内执行任务不一样,

简述:

一开始llm一般会列出一个任务清单,

1. 前者也就是我们,相当于llm每完成一个任务都会把整个清单以及之前自己是怎么做的在做什么全部重新看一遍,
>虽然比较废词元(token)和上下文窗口大小,而且这个项目也不够智能,但谁叫这个东西从上到下完全免费呢?

2. 后者llm每完成一个任务会直接往下进行,不会看一眼之前的东西
>节省,专注性强,不容易提示词污染,(没咋研究,剩下的不知道了)

---

## 食用步骤

- 安装油猴脚本`PokerAgent.js`
- 安装python,建议python版本3.12,3.14也行,不过我用着3.14有bug,看`commands.md`的`# 紧急告示栏`
- 在项目根目录`shift+右键`选择`在终端中打开`,输入`python agent_gui.py`
- 把你的提示词,`PokerAgent-使用指南.md`和需求发送给网页端llm,并告诉他使用PokerAgent

## 注意事项

- 目前建议全程人工值守,因为如果出了报错llm又不知道哪错了他就会开始瞎猜,然后发生提示词污染导致那次会话基本废了(如果网站那边没有提供删除单次对话的功能的话),而且即使不废也会浪费上下文,我在考虑加入重试次数机制,llm发出未知指令超过几次就发一遍指令列表
- 目前已经可用,但还存在一些问题
- 默认适配chatglm.cn,他们前端写的好,容易适配,deepseek不知道是防爬还是单纯写的拉,结果是适配很难弄
- 因为llm会遗忘早期对话,考虑在固定的对话次数后重新发送一遍提示词
- 以越狱方式的"系统提示词"其实并不好,他会抹杀llm的个性以及其他的一些东西,会变傻,建议以"用户的额外要求"或者"使用指南"的方式来
- llm会瞎猜指令,没办法解决,如果llm在第一次对话时拿到了指令列表,之后过100次对话后即使事实上llm已经把指令列表忘干净了,他也依然不会再看一遍指令列表,而是会选择瞎猜
